# 문서 아카이브

> 갱신되면서 대체된 **옛 문서**를 버리지 않고 모아 두는 곳.
> **여기 있는 것은 어느 것도 현행이 아니다.** 현재 상태를 알고 싶으면
> `docs/` 본체를 본다.

## 왜 지우지 않고 두나

옛 문서는 「그때는 이렇게 알고 있었다」는 기록이다. 설계가 왜 바뀌었는지
되짚을 때, 결정 카드([DECISIONS.md](../DECISIONS.md))만으로는 부족하고
바뀌기 전 문서를 나란히 놓아야 보이는 것이 있다.

## 넣을 때 규칙

- 폴더 이름은 `YYYY-MM-DD_무엇`. 날짜는 **그 문서가 마지막으로 유효했던 시점**.
- 넣기 전에 대체한 현행 문서가 실제로 있는지 확인한다. 대체 없이 넣는 것은
  아카이빙이 아니라 그냥 삭제다.
- 아카이브 안의 문서는 **고치지 않는다.** 고칠 일이 있으면 현행 쪽이다.
