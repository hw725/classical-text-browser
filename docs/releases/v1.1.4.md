# v1.1.4 릴리스 노트

날짜: 2026-05-08

## 주요 변경

- 설정이 준비되어 있으면 본체 시작 스크립트에서 외부 SikuRoBERTa 표점 Docker 서비스를 자동 기동합니다.
- 본체의 외부 표점 기본 URL을 로컬 서비스(`http://127.0.0.1:8765`)로 맞추고, 원 모델 출처 표기를 문서화했습니다.
- Windows `start_server.bat`에서 OpenAI OAuth 프록시를 자동 실행하고 포트를 감지합니다.
- 주석/인용 탭에서 TextBlock, LayoutBlock, 기본 블록 흐름을 이어받도록 블록 선택 폴백을 보강했습니다.
- 원문 드래그로 인용 마크를 만들 수 있게 하고, 원본 블록을 다시 찾지 못할 때 저장된 원문 스냅샷으로 통합 컨텍스트를 구성하도록 수정했습니다.
- LLM 5단 폴백, 외부 표점 설정, 출처 표기, 시작 스크립트 관련 사용자/개발자 문서를 동기화했습니다.
