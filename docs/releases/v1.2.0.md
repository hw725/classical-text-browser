# v1.2.0 릴리스 노트

날짜: 2026-07-17
범위: v1.1.4 이후 15개 커밋

## 한 줄 요약

경로 설정 없이 **PDF를 끌어다 놓으면 바로 작업이 시작되는** 온보딩 개편 —
서고·문헌 ID·해석 저장소가 전부 자동으로 준비됩니다.

## 주요 변경

### 온보딩: 드래그 앤 드롭으로 바로 시작 (D-052, D-054)

- PDF·이미지 파일(이미지 폴더 통째도 가능)을 창 안 어디에나 끌어다 놓으면
  새 문헌 등록이 시작됩니다. 폴더 안 이미지들은 파일명 숫자 정렬 순서로
  1권의 PDF로 묶입니다.
- 서고가 없으면 기본 서고(`내 문서/고전서지서고`)를 자동으로 만들어
  연결합니다 (`POST /api/library/quick-start`). 위치는 설정에서 변경 가능.
- 문헌 ID는 비워 두면 서버가 자동 생성합니다 — 한자·한글 파일명이면
  `doc_YYYYMMDD` 형식, 충돌 시 `_2` 접미사. 제목은 원본 파일명(한자 보존)이
  자동으로 채워집니다.
- 문헌 생성 시 기본 해석 저장소(`문헌ID_interp`, hybrid)가 함께 만들어져,
  OCR·교정 후 곧바로 표점·번역·주석 작업에 들어갈 수 있습니다.
- 빈 서고·미연결 첫 화면에 드래그 앤 드롭 시작 안내를 추가했습니다.

### 시작 경험: 보이는 창은 하나 (D-054)

- `start_server.bat` 실행 시 보이는 터미널 창이 1개가 됐습니다.
  브라우저 오프너의 임시 cmd 창을 제거하고, OpenAI OAuth 프록시는 창 없이
  백그라운드로 돌며 출력을 `logs\openai-oauth.log`에 남깁니다
  (OAuth 첫 로그인 안내도 이 파일에서 확인). 메인 창을 닫으면 프록시도
  함께 종료되어 잔여 프로세스가 없습니다.
- 외부 표점 서비스(SikuRoBERTa)의 모델이 첫 호출 때 로드되어 수 분 걸리는
  동안, 표점 편집기가 경과 시간 진행 표시와 첫 실행 안내를 보여줍니다.
  사전 연결 확인 엔드포인트(`GET /api/llm/punctuation/external/health`)가
  추가됐고 호출 타임아웃이 60→300초로 늘었습니다.

### UI·아이콘 정비 (D-052)

- 파비콘 신설 (`favicon.svg`, 펼친 책 모티브).
- 아이콘 체계를 Feather 계열 stroke SVG로 수렴: Git 이력 아이콘 교체,
  PDF 툴바의 불명확 글리프(⊞ ◑ ━)와 경고 표시 통일, 컬러 이모지 제거
  (주석 유형 기본 아이콘 🏷️ → 註, 모델 목록 👁 → [비전] 텍스트).

### 구조·안정성 (D-053)

- 저장소 ID 규칙을 `core/repo_id.py` 단일 진실원으로 통합 (기존 8곳 복제).
- 6개 라우터 약 95지점의 경로 조립을 `require_repo_path()` 검증 호출로
  통일 — 모든 read API가 ID 형식(경로 탈출)을 검증합니다.
- `create-from-url` 실패 시 부분 생성물을 롤백해 “실패 = 아무것도 안 남음”을
  보장합니다 (create-from-files와 동일한 시맨틱).
- 사이드바 갱신 이중 구현을 제거하고 `loadLibraryInfo`로 단일화.
- LLM 응답이 잘린 채 복구되면 화면 경고로 알립니다 (조용한 누락 방지).
- 관측 가능성 Phase 1: LLM 사용 로그를 OTel 시맨틱 컨벤션 명명과
  이중 기록으로 정렬 (D-051).
- 온보딩 경로에 이 저장소 첫 API 레벨 테스트(`tests/test_onboarding_api.py`)
  추가 — 전체 테스트 490개.

## 호환성·행동 변화

- 형식이 잘못된 문헌/해석 ID로 API를 호출하면 이전의 404 대신
  **400 + 안내 메시지**를 받습니다 (프론트엔드 영향 없음).
- `POST /api/documents/create-from-files`의 `doc_id`가 선택 항목이 됐고,
  응답에 `interpretation_id`·`warning` 필드가 추가됐습니다.
- `logs/` 디렉터리는 git 추적에서 제외됩니다 (런타임 산출물).
