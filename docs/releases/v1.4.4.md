# v1.4.4 — 판정 모델을 OpenRouter 목록에서 고르기

날짜: 2026-10-18 · 범위: v1.4.3 이후 · **되돌릴 수 없는 변화 없음**(앱 설정 `config.json`에 판정 모델 선택 칸 `decision_models`가 더해질 뿐이고, 서고 파일은 바뀌지 않습니다)

## 설치

- Windows — 아래 **Assets** 의 `CTB-Setup.exe` → 두 번 누르기 → 폴더·엔진 고르기 → 「설치」 → 「지금 실행」
- 이미 깔린 PC — `start_server.bat`을 켜면 저절로 새 판을 받습니다(받지 못하면 까닭을 알립니다)
- macOS·Linux — zip을 풀고 `./install.sh`

## 추가

- **판정 모델을 고를 수 있습니다** (D-142). 설정 → 《판정 모델》의 「판정 모델 고르기 (OpenRouter)」에 칸이 셋 있고, 고르는 즉시 저장됩니다.

  | 칸 | 쓰는 곳 | 기본값 |
  |---|---|---|
  | 텍스트 모델 | 편성 「판정 모델로 고르기」의 본문 판정과 목차 대조 | `typesafe/jev-1.14` |
  | 텍스트 폴백 모델 | 편성 본문 판정에서 텍스트 모델이 실패한 호출만 대신 답함(목차 대조는 폴백 없음, 《폴백 없음》도 고를 수 있음) | `perplexity/pplx-decider-v1.2` |
  | 이미지 모델 | 「말로 지시」 ① 자동 스캔의 《무슨 글인가》 | `perplexity/pplx-decider-v1.2` |

- 고를 수 있는 모델은 **OpenRouter의 판정 모델 목록**을 그대로 받아 옵니다. OpenRouter에 새 모델이 올라오면 칸에 저절로 나타납니다(설정을 열 때 받아 오고, 받은 목록은 한 시간 동안 다시 씁니다). 인터넷에 닿지 않으면 앱에 든 목록을 보입니다. 이미지 칸에는 이미지를 받는 모델만 나옵니다.

## 바뀜

- **판정 모델은 OpenRouter 키 하나로 부릅니다.** TypeSafe·Perplexity·Cloudflare에 직접 붙는 길은 《추가 예정》으로 칸 아래에 적혀 있고, 지금은 그 키가 서고에 있어도 쓰지 않습니다. 지난 판에서 TypeSafe 키나 Cloudflare 키만 넣어 쓰셨다면 설정 → 《판정 모델》에서 OpenRouter 키를 넣어 주세요. 키가 없으면 「말로 지시」의 《종류 판정 모델》에서 판정 모델 항목이 흐려지고 기본 비전 모델(kimi-k3)로 스캔하며, 편성 「판정 모델로 고르기」는 키를 넣으라고 안내합니다.
- 설정 → 《판정 모델》에는 OpenRouter 한 줄만 있습니다(TypeSafe·Perplexity·Cloudflare 키 줄은 없어졌습니다).
- **자동 스캔 이미지 판정에 Cloudflare 무료 몫이 없어졌습니다.** 판정 모델로 스캔하면 쪽마다 OpenRouter 유료 호출이 나갑니다(보내기 전 어림이 뜹니다 — `perplexity/pplx-decider-v1.2`면 1,000쪽에 약 $0.05). 「말로 지시」의 《종류 판정 모델》에서 판정 모델은 《판정 모델 — <설정의 이미지 모델>》 하나로 합쳐졌습니다.
- 자동 스캔에서 이미지 모델이 답하지 못한 쪽은 그 쪽부터 기본 비전 모델(kimi-k3)이 이어 답합니다. 결과 줄에 《넘어감》으로 따로 남습니다.
- 화면 안내문·문서의 «» 괄호가 《》로 통일되었습니다.

---

- Added: Pick the decision models in Settings → Decision models — text, text fallback and image slots. The list comes from OpenRouter's decision models and updates by itself; defaults are `typesafe/jev-1.14` (text) and `perplexity/pplx-decider-v1.2` (text fallback, image).
- Changed: Decision models are now called through OpenRouter only (one OpenRouter key). Direct TypeSafe, Perplexity and Cloudflare connections are planned and not used in this version. Pages the image model cannot answer fall back to the default vision model. The Cloudflare free tier step of the image check is gone — scanning with a decision model makes paid OpenRouter calls (an estimate is shown before sending).
- Changed: «» brackets in on-screen messages are now 《》.
