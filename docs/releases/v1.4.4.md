# v1.4.4 — 판정 모델을 OpenRouter 목록에서 고르기 · 《자동》 기본 모델 갱신

날짜: 2026-10-18 · 범위: v1.4.3 이후 · **되돌릴 수 없는 변화 없음**(앱 설정 `config.json`에 판정 모델 선택 칸 `decision_models`가 더해지고, 서고 `.env`에 기본 모델 줄이 고른 경우에만 더해질 뿐이며, 서고 파일은 바뀌지 않습니다)

## 설치

- Windows — 아래 **Assets** 의 `CTB-Setup.exe` → 두 번 누르기 → 폴더·엔진 고르기 → 「설치」 → 「지금 실행」
- 이미 깔린 PC — `start_server.bat`을 켜면 저절로 새 판을 받습니다(받지 못하면 까닭을 알립니다)
- macOS·Linux — zip을 풀고 `./install.sh`

## 추가

- **판정 모델을 고를 수 있습니다** (D-142). 설정 → 《판정 모델》의 「판정 모델 고르기 (OpenRouter)」에 칸이 셋 있고, 고르는 즉시 저장됩니다.

  | 칸 | 쓰는 곳 | 기본값 |
  |---|---|---|
  | 텍스트 모델 | 편성 「판정 모델로 고르기」의 본문 판정과 목차 대조 | `typesafe/jev-1.14` |
  | 텍스트 폴백 모델 | 편성 본문 판정에서 텍스트 모델이 실패한 호출만 대신 답함(목차 대조는 폴백 없음, 《폴백 없음》도 고를 수 있음) | `perplexity/pplx-decider-v1.2` |
  | 이미지 모델 | 「말로 지시」 ① 자동 스캔의 《무슨 글인가》 | `perplexity/pplx-decider-v1.2` |

- 고를 수 있는 모델은 **OpenRouter의 판정 모델 목록**을 그대로 받아 옵니다. OpenRouter에 새 모델이 올라오면 칸에 저절로 나타납니다(설정을 열 때 받아 오고, 받은 목록은 한 시간 동안 다시 씁니다). 인터넷에 닿지 않으면 앱에 든 목록을 보입니다. 이미지 칸에는 이미지를 받는 모델만 나옵니다.

- **《자동》일 때 쓰는 기본 모델을 고를 수 있습니다** (D-143). 설정 → LLM 연결의 Ollama 카드와 OpenAI (OAuth) 카드에 「자동 모드 기본 모델」 칸이 생겼고(카드가 《연결됨》일 때 보입니다. OAuth 카드에는 「추론 강도」도), 고르는 즉시 서고 `.env`에 저장됩니다. `.env`에 직접 적을 수도 있습니다 — `OLLAMA_TEXT_MODEL`·`OPENAI_OAUTH_MODEL`·`OPENAI_OAUTH_EFFORT`.
- **앞 순위가 실패해 다음 순위로 넘어가면 화면에 알립니다** (D-143). 오른쪽 위에 《LLM 앞 순위가 실패해 다음 순위로 넘어갔습니다: …》가 뜨고 무엇이 왜 실패했고 누가 답했는지 보입니다. 진행률이 흐르는 긴 작업(스트리밍)과 배치 OCR은 서버 기록에만 남고, 연결되지 않은 공급자를 건너뛴 것은 알리지 않습니다(카드에 이미 보입니다). 기본 모델을 바꾸면 10분 결과 캐시도 비웁니다.
- **작업 화면의 「모델」 칸이 고른 모델을 기억합니다** (D-143). OCR·편성·표점·번역·주석·말로 지시·노트 틀의 칸에서 고른 모델이 칸마다 이 브라우저에 남아 새로고침해도 그대로입니다(지난 판까지는 매번 《자동》으로 돌아갔습니다). 기억한 모델을 지금 쓸 수 없으면 《자동》으로 두고 알립니다.

## 바뀜

- **《자동》의 기본 모델이 바뀌었습니다** (D-143). Ollama 글 작업(번역·말로 넣기 등)은 `gemma4:e4b` → **`kimi-k3:cloud`**, kimi-k3를 받아 두지 않은 PC는 받아 둔 `glm-5.2:cloud` → `glm-5.3:cloud`로 대신하고 그 사실을 알립니다(로컬 모델로는 대신하지 않습니다), Ollama 이미지(OCR) 기본도 `gemma4:cloud` → **`kimi-k3:cloud`**(glm-5.2·5.3은 이미지를 받지 않습니다, 설치도 이 모델 하나를 등록합니다), ChatGPT 계정은 `gpt-5.4-mini` → **`gpt-6.1-sol`로** 바뀌었습니다. 추론 강도는 호출이 따로 정하지 않은 글 작업에 medium, 사고를 끄는 호출(OCR·말로 넣기·목차·편성 등)에 low가 갑니다. 옛 기본 모델을 받아 두지 않은 PC(클라우드 모델만 쓰는 PC)에서는, 그리고 ChatGPT 프록시가 `gpt-5.4-mini`를 더 이상 내지 않아, 《자동》의 앞 두 순위가 조용히 실패하고 다음 순위(키가 있으면 Gemini, 유료)가 대신 답하고 있었습니다. 표점·주석은 전처럼 《자동》에서 Ollama를 건너뜁니다. 두 모델 모두 구독 한도를 씁니다(금액 0). 기본 모델이 그 PC의 목록에 없으면 부르지 않고 다음 순위로 넘어가며, 카드에도 그렇게 적힙니다.
- **판정 모델은 OpenRouter 키 하나로 부릅니다.** TypeSafe·Perplexity·Cloudflare에 직접 붙는 길은 《추가 예정》으로 칸 아래에 적혀 있고, 지금은 그 키가 서고에 있어도 쓰지 않습니다. 지난 판에서 TypeSafe 키나 Cloudflare 키만 넣어 쓰셨다면 설정 → 《판정 모델》에서 OpenRouter 키를 넣어 주세요. 키가 없으면 「말로 지시」의 《종류 판정 모델》에서 판정 모델 항목이 흐려지고 기본 비전 모델(kimi-k3)로 스캔하며, 편성 「판정 모델로 고르기」는 키를 넣으라고 안내합니다.
- 설정 → 《판정 모델》에는 OpenRouter 한 줄만 있습니다(TypeSafe·Perplexity·Cloudflare 키 줄은 없어졌습니다).
- **자동 스캔 이미지 판정에 Cloudflare 무료 몫이 없어졌습니다.** 판정 모델로 스캔하면 쪽마다 OpenRouter 유료 호출이 나갑니다(보내기 전 어림이 뜹니다 — `perplexity/pplx-decider-v1.2`면 1,000쪽에 약 $0.05). 「말로 지시」의 《종류 판정 모델》에서 판정 모델은 《판정 모델 — <설정의 이미지 모델>》 하나로 합쳐졌습니다.
- 자동 스캔에서 이미지 모델이 답하지 못한 쪽은 그 쪽부터 기본 비전 모델(kimi-k3)이 이어 답합니다. 결과 줄에 《넘어감》으로 따로 남습니다.
- 화면 안내문·문서의 «» 괄호가 《》로 통일되었습니다.

---

- Added: Pick the decision models in Settings → Decision models — text, text fallback and image slots. The list comes from OpenRouter's decision models and updates by itself; defaults are `typesafe/jev-1.14` (text) and `perplexity/pplx-decider-v1.2` (text fallback, image).
- Changed: Decision models are now called through OpenRouter only (one OpenRouter key). Direct TypeSafe, Perplexity and Cloudflare connections are planned and not used in this version. Pages the image model cannot answer fall back to the default vision model. The Cloudflare free tier step of the image check is gone — scanning with a decision model makes paid OpenRouter calls (an estimate is shown before sending).
- Changed: «» brackets in on-screen messages are now 《》.
- Changed: In "Auto" mode the default Ollama model is now `kimi-k3:cloud` for both text and images (the installer registers it instead of `gemma4:cloud`; if it is not installed, text falls back to an installed `glm-5.2:cloud` then `glm-5.3:cloud` with a notice, never to a local model), and the default text model is `kimi-k3:cloud` for Ollama and `gpt-6.1-sol` (reasoning effort medium) for the ChatGPT account. The old defaults were no longer available, so the first two providers failed silently. A default model missing from the provider's list is skipped instead of called.
- Added: Pick the Auto-mode default model (and reasoning effort for ChatGPT) on the Ollama and OpenAI (OAuth) cards in Settings → LLM connections, or set `OLLAMA_TEXT_MODEL`, `OPENAI_OAUTH_MODEL`, `OPENAI_OAUTH_EFFORT` in the library `.env`. When an earlier provider fails and the next one answers, a notice now appears on screen. The model picked in each screen's Model box is now remembered across reloads (per box, in this browser).
