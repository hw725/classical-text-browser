# v1.3.0 — 자동 트리 생성 및 교정

날짜: 2026-09-05 · 범위: v1.2.3 이후

**목차·해제·들여쓰기를 읽어 개요를 자동으로 세우고, 기사 경계를 눈으로 옮깁니다.**
설치부터 AI 연결까지 화면 안에서 끝나고, 첫 화면이 가벼워졌습니다.

## 새로 할 수 있는 것

- **자동 트리** — 사이드바 「내용」 단추 하나로 **묶음 > 기사 > 조각** 개요가 섭니다.
  목차 있는 책은 목차대로, 「卷之一」 같은 행은 묶음으로.
- **경계를 눈으로** — 원본 이미지나 교정 텍스트를 **찍어** 경계를 놓고, ▲▼로 한 행씩 옮기고,
  ⇤⇥로 깊이, ×로 합칩니다. 쪽·행 번호를 세지 않습니다.
- **기사를 고르면 다섯 편집기가 따라옵니다** — 표점·현토·번역·주석·인용이 사이드바에서 고른
  기사로 함께 맞춰집니다.
- **편성은 문헌의 것** — 해석 저장소를 고르지 않아도 편성이 됩니다. 나중에 글자를 고쳐도 개요가
  따라옵니다.

## 처음 쓰기가 쉬워졌습니다

- **처음 설정 안내** — 서고 만들기 → 글자 인식 엔진 → AI 연결, 세 단계.
- **엔진·키·로그인 전부 단추로** — 고서·일본어 엔진은 「설치」, API 키는 칸에 붙여 넣고 「저장」,
  ChatGPT 계정은 「시작·로그인」. 터미널도 `.env`도 열지 않습니다.
- **새 판은 앱 안에서** — 설정 ▸ 앱 업데이트 ▸ 「새 판 확인」 → 「받기」.
- **`install.bat`이 고쳐졌습니다** — 「'모장으로'은(는) 내부 또는 외부 명령이 아닙니다」 오류 해결.
  설치 마지막에 글자 인식 모델(약 240MB)을 미리 받아 첫 OCR이 멈춰 보이지 않게 했습니다.

## 빨라지고 편해진 것

- **PDF를 통째로 받지 않습니다** — 12쪽을 여는 데 81MB → 1.9MB.
- **첫 화면 7MB → 1.5MB** — 5MB짜리 웹폰트를 내려받지 않고 브라우저 기본 글꼴을 씁니다.
- **설정 화면이 9초 → 1.5초** — Ollama 주소를 `localhost`에서 `127.0.0.1`로(Windows가 IPv6를 먼저
  시도해 호출마다 2초를 버렸습니다), 모델 목록은 10분 기억, 프록시 포트 탐색은 동시에.
- **교정 글씨** 기본 20px, 「가− 가+」로 조절.
- **모델 목록이 낡지 않습니다** — 새 모델(gpt-6-astra 등)이 나오면 드롭다운에 그대로 뜹니다.
  키를 넣으면 새로고침 없이 바로 보입니다.
- **명령줄(`ctb ocr`)** — `--model 9`처럼 번호로 모델을 고르고, 실행 전에 어느 모델이 도는지
  한 줄 찍습니다. `ctb config`로 자주 쓰는 옵션을 기억합니다.
- 「검증 결과」·「비고」 패널이 실제로 동작합니다.
- **추출 모드에서 PaddleOCR을 고르면 언어 칸**이 뜹니다(기본 한국어). 전에는 언어를 넘기지 않아
  중국어 모델로 돌았습니다.
- **Ollama가 떠 있는데 «없음»으로 보이던 것** — 주소를 `127.0.0.1`로 부르고, `.env`에 `localhost`로
  적혀 있어도 바꿔 부릅니다.

## 새 판으로 갈아타기

- **설정 ▸ 앱 업데이트 ▸ 「새 판 확인」 → 「받기」**, 그 뒤 서버를 껐다 켭니다.
- zip으로 쓰고 있었다면 새 zip을 받아 폴더를 덮어씁니다. 서고는 앱 폴더 밖이라 그대로입니다.

## 주의

- 해석 저장소를 **처음 여는 순간** 옛 단위·경계 파일을 새 자리로 옮깁니다. 손댈 것 없고 옛 파일도
  남습니다. 다만 **이 판에서 연 서고를 v1.2로 다시 열면 단위가 비어 보입니다** — 받기 전에
  설정 ▸ 서고 백업을 한 번 해 두세요.
- 손으로 쌓은 이체자 사전은 더 이상 앱에 들어 있지 않습니다. 서고의 「이체자」 화면에서 만들거나
  JSON·CSV로 가져옵니다.

## 아직 안 되는 것

- 卷 이름이 행 가운데 오는 판식은 자동 트리가 묶음으로 잡지 못합니다 — 손으로 넣습니다.
- 「찍기」는 지금 보는 쪽 안에서만 됩니다.

설계 근거는 `docs/DECISIONS.md` D-092 ~ D-109.
