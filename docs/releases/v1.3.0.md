# v1.3.0 — 자동 트리 생성 및 교정

날짜: 2026-09-06 · 범위: v1.2.3 이후

**목차·해제·들여쓰기를 읽어 개요를 자동으로 세우고, 기사 경계를 눈으로 옮깁니다.**
설치부터 AI 연결까지 화면 안에서 끝나고, 첫 화면이 가벼워졌습니다.

## 설치 (Windows)

1. 이 페이지 아래 **Assets**의 **`CTB-Setup.exe`**를 받아 두 번 누릅니다.
2. 창에서 설치 폴더와 글자 인식 엔진을 고르고 「설치」 — 나머지는 알아서 합니다(처음 5~10분).
3. 「지금 실행」. 다음부터는 바탕화면의 **「고전서지 브라우저」** 아이콘으로 켭니다.

- Windows가 «알 수 없는 앱»이라고 막으면 「추가 정보」 ▸ 「실행」(서명 없는 프로그램이라 그렇습니다).
- 이미 zip으로 깔아 둔 PC도 같은 폴더를 고르면 그 위에 덮어씁니다. 서고·키는 그대로입니다.
- macOS·Linux는 zip을 풀고 `./install.sh`.

## 새로 할 수 있는 것

- **자동 트리** — 사이드바 「내용」 ▸ 「자동 트리」 한 번으로 **묶음 > 기사 > 조각** 개요가 섭니다.
- **트리를 누르면 원본에 점선** — 기사를 고르면 원본 이미지의 시작 행이 점선으로 표시됩니다.
- **경계를 눈으로** — 원본이나 교정 텍스트를 **찍어** 경계를 놓고, ▲▼·⇤⇥·×로 다듬습니다.
- **기사를 고르면 다섯 편집기가 따라옵니다** — 표점·현토·번역·주석·인용이 그 기사로 맞춰집니다.
- **편성은 문헌의 것** — 해석 저장소 없이 편성이 되고, 글자를 고쳐도 개요가 따라옵니다.
- **인덱스** — 작업 갈피가 오른쪽 세로 줄로 갔습니다. 켜진 인덱스를 다시 누르면 패널이 접힙니다.

## 처음 쓰기가 쉬워졌습니다

- **설치 파일 하나** — `CTB-Setup.exe`를 두 번 누르면 폴더·엔진을 고르고 끝까지 알아서 깝니다. 바탕화면 아이콘으로 켭니다.
- **처음 설정 안내** — 서고 만들기 → 글자 인식 엔진 → AI 연결, 세 단계.
- **엔진·키·로그인 전부 단추로** — 「설치」·「저장」·「시작·로그인」·「로그인」·「모델 받기」. 터미널을 열지 않습니다.
- **새 판은 저절로** — 서버를 켤 때 받고, 열어 둔 앱에는 알림이 뜹니다. zip으로 설치한 폴더도 됩니다.
- **설치가 고쳐졌습니다** — `install.bat` 오류 해결, 파이썬이 없어도 됩니다, 글자 인식 모델을 미리 받습니다. Ollama가 있으면 기본 비전 모델 `gemma4:cloud`를 등록합니다(내려받는 파일 없음, 몇 초).

## 빨라지고 편해진 것

- **첫 화면과 PDF가 가볍습니다** — 쪽 하나를 보려고 PDF 전체를 받지 않고, 웹폰트를 내려받지 않습니다.
- **설정 화면과 서버 켜기가 빠릅니다** — 9초 → 1.5초, 17초 → 0.3초.
- **Ollama가 떠 있는데 «없음»으로 보이던 것**을 고쳤습니다. 비전 모델이 없으면 기본 모델 `gemma4:cloud`를 저절로 등록합니다 — 클라우드 모델이라 내려받는 파일이 없고, 쓰려면 카드의 「로그인」.
- **비전 모델을 골라 받습니다** — Ollama 카드의 「모델 받기」가 후보 목록(클라우드 / 내 PC용 1.9~9.6GB)을 보여 주고 고른 것을 받습니다. 로그인하지 않을 PC는 내 PC용 모델을 고르면 됩니다. 목록에 없는 이름은 「직접 입력」.
- **ChatGPT 계정(OAuth)으로 글자 읽기**가 됩니다.
- **모델 목록이 낡지 않습니다** — 새 모델이 나오면 드롭다운에 바로 뜹니다.
- **교정 글씨** 기본 20px, 「가− 가+」로 조절.
- **추출 모드의 PaddleOCR 언어 칸** — 기본 한국어.
- **명령줄 `ctb ocr`** — `--model 9`처럼 번호로 고르고, `ctb config`로 자주 쓰는 옵션을 기억합니다.
- 「검증 결과」·「비고」 패널이 동작하고, 문헌을 열자마자 누른 쪽이 바로 그려집니다.

## 새 판으로 갈아타기

- `start_server.bat`을 켜면 저절로 받습니다. 열어 둔 앱에서는 설정 ▸ 앱 업데이트 ▸ 「받기」, 그 뒤 서버를 껐다 켭니다.
- v1.3.0 이전 판을 zip으로 깔았던 PC는 위 `CTB-Setup.exe`를 한 번 돌립니다(같은 폴더 선택). 그 뒤로는 저절로 받습니다.

## 주의

- 해석 저장소를 **처음 여는 순간** 옛 단위·경계 파일을 새 자리로 옮깁니다. 옛 파일도 남습니다.
  **이 판에서 연 서고를 v1.2로 다시 열면 단위가 비어 보입니다** — 받기 전에 설정 ▸ 서고 백업.
- 손으로 쌓은 이체자 사전은 앱에 들어 있지 않습니다. 「이체자」 화면에서 만들거나 JSON·CSV로 가져옵니다.

## 아직 안 되는 것

- 卷 이름이 행 가운데 오는 판식은 자동 트리가 묶음으로 잡지 못합니다 — 손으로 넣습니다.
- 「찍기」는 지금 보는 쪽 안에서만 됩니다.

설계 근거는 `docs/DECISIONS.md` D-092 ~ D-114.
